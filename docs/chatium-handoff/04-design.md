# 04. Дизайн

## Главное про перенос дизайна

Chatium рендерит мобильный UI через **Server-Driven UI** (нативный рендер по JSON) — это **не webview**. Поэтому текущая вёрстка (Tailwind, React-компоненты, произвольный CSS, canvas-анимации) **не переносится 1:1** — экраны пересобираются на компонентах Chatium. Но **визуальный язык воспроизводим** их системой стилей: `backgroundColor`, `backgroundGradient`, `backgroundImage`, `borderRadius`, `color`, `fontSize/fontFamily/fontWeight`, `opacity`, `elevation`/`shadowColor`, `textShadow`, `transform`, полный flexbox, `position: absolute`.

Относитесь к оригиналу как к **макету**, а не к исходнику.

## Дизайн-токены

**Тема — тёмная.**

| Токен | Значение | Где |
|---|---|---|
| Фон (background) | `#000000` (чёрный) | весь app |
| Текст (foreground) | `#FFFFFF` (белый) | весь app |
| Шрифт | **Wix Madefor Display** (Google Font) | весь app |

**Цвета категорий** (эталон — `components/BreathVisual.tsx`), используются в блобах/акцентах:

| Категория | Ярлык | RGB | HEX |
|---|---|---|---|
| relax | SLOW | `139, 92, 246` | `#8B5CF6` (фиолетовый) |
| balance | GROUND | `59, 130, 246` | `#3B82F6` (синий) |
| energize | RISE | `236, 72, 153` | `#EC4899` (розовый) |

Блобы рисуются как мягкие круги/радиальные градиенты соответствующего цвета с полупрозрачными «пузырьками» поверх (alpha ≈ 0.18).

> **Риск — шрифт:** подтвердить, что Chatium даст загрузить Wix Madefor Display через `fontFamily`. Если нет — подобрать ближайший гротеск, иначе вид «поедет».

## «Дышащий» блоб — ключевой элемент бренда (риск)

На главной и в онбординге — крупный **непрерывно анимированный** блоб (пульсация + дрейф пузырьков), задающий «дыхательный» ритм. В оригинале это `<canvas>` с анимацией по кадрам (`components/BreathVisual.tsx`, `requestAnimationFrame`).

**Проблема:** в документации Chatium подтверждены `transform` и статические градиенты, но **непрерывная keyframe/loop-анимация не подтверждена**. Варианты по убыванию желательности:
1. Нативная анимация Chatium, если поддерживается (уточнить у support).
2. Короткое зацикленное **видео** блоба через медиасервис (видео Chatium умеет).
3. **Lottie**, если поддерживается.
4. Статичная картинка-блоб (`public/images/black_blob_5.png`, `onboarding-blob.png`) — минимальный запасной вариант без анимации.

Это первый вопрос к платформе (см. `00-README.md`).

## Скриншоты (приложить при передаче)

Дизайн-токены выше **проверены на живом приложении** (`npm run dev`): тёмная тема (`#000`/`#fff`), шрифт Wix Madefor, «дышащий» блоб фиолетового цвета (`#8B5CF6`) на онбординге — всё подтверждается. Публичные экраны, которые видно без входа:
- **Онбординг** — центральный анимированный блоб (два пересекающихся кольца + пульсирующая точка), прогресс из 3 сегментов, заголовок «Дыши осознанно», кнопки «Далее» / «Пропустить».
- **Логин** — логотип «плохие будды / badbuddhas», поля Email/Password, белая кнопка «Sign in», «Forgot password?», «Sign up».

**Внутренние экраны (главная, каталог, плеер, профиль, подписка) закрыты аутентификацией** — их скриншоты нужно снять из-под залогиненного пользователя. Это должен сделать владелец проекта (у кого есть тестовый Telegram/email-доступ): запустить `npm run dev`, войти, пройти по экранам и приложить PNG в эту папку. Референс поведения каждого экрана — в `01-product-spec.md`.

Статические визуальные ассеты — в `public/images/` (логотипы, блобы, онбординг-иллюстрации); их реестр — в `05-assets.md`.
