# 11. Пошаговые промпты для ИИ-агента Chatium

Если строить не одним махом, а по частям — идите шагами. Каждый шаг: промпт → ожидаемый результат → как проверить. Выполняйте по порядку; предыдущие шаги — контекст для следующих. Основной контекст берите из `10-agent-master-prompt.md` и `01`–`05`.

---

## Шаг 1. Модель данных

**Промпт:** «Создай в Heap таблицы: users, practices, user_practices, user_stats, favorites, subscriptions с полями и связями из спецификации (см. модель данных). user_stats создаётся автоматически вместе с users. Добавь уникальность favorites(user_id, practice_id) и уникальность users.telegram_id и users.email.»
**Результат:** типизированные таблицы Heap.
**Проверка:** создать тестового пользователя — рядом появляется user_stats; повтор telegram_id не создаёт дубль.

## Шаг 2. Авторизация через Telegram + триал

**Промпт:** «Сделай вход через Telegram Mini App: принимай initData, верифицируй подпись по токену бота, находи/создавай пользователя в users по telegram_id. При создании ставь trial_ends_at = now + 14 дней. Добавь функцию hasAccess = is_premium ИЛИ trial_ends_at > сейчас.»
**Результат:** пользователь входит из Telegram, есть триал и hasAccess.
**Проверка:** открыть Mini App → создаётся пользователь с триалом; hasAccess = true в первые 14 дней.

## Шаг 3. Каталог

**Промпт:** «Экран каталога: список practices по sort_order, карточка (обложка, название_ru, инструктор, длительность, значок premium). Фильтр по инструктору. Тап → экран практики.»
**Результат:** каталог из Heap.
**Проверка:** добавить пару практик вручную — видны и сортируются; фильтр работает.

## Шаг 4. Медиа + плеер

**Промпт:** «Загрузи аудио практик в медиасервис и пропиши audio_url. Сделай экран плеера: play/pause, перемотка по прогресс-бару, текущее время и длительность, стриминг с seek. По окончании вызывай запись сессии.»
**Результат:** рабочий проигрыватель.
**Проверка:** практика играет, перемотка работает, длительность корректная, фоновое воспроизведение ок.

## Шаг 5. Избранное

**Промпт:** «Кнопка "в избранное" на карточке и в плеере: тап добавляет/убирает запись в favorites (оптимистично, с откатом при ошибке). Экран Избранное показывает избранные практики.»
**Результат:** избранное работает и сохраняется.
**Проверка:** добавил → появилось в Избранном и осталось после перезахода.

## Шаг 6. Стрик и статистика

**Промпт:** «По завершении практики: вставь запись в user_practices, затем пересчитай стрик из истории (уникальные даты в TZ Europe/Moscow; current_streak — серия до последней даты; longest_streak — максимум; total_practices, total_minutes; longest/total не уменьшать). Расчёт идемпотентный.»
**Результат:** стрик и статистика в user_stats.
**Проверка:** практики в разные дни дают верный current_streak; повторный пересчёт не ломает значения.

## Шаг 7. Премиум-гейтинг

**Промпт:** «Если практика is_premium и у пользователя нет hasAccess — вместо плеера показывай/веди на экран подписки. Иначе играй.»
**Результат:** премиум закрыт для не-подписчиков вне триала.
**Проверка:** пользователь без премиума и с истёкшим триалом упирается в пейволл; с триалом/премиумом — играет.

## Шаг 8. Профиль

**Промпт:** «Экран профиля: current_streak, longest_streak, total_practices, total_minutes из user_stats; статус подписки и дни триала; привязка email; выход.»
**Результат:** профиль со статистикой.
**Проверка:** цифры совпадают с реальными практиками; статус подписки корректен.

## Шаг 9. Подписка и оплата

**Промпт:** «Экран подписки: оффер → оплата → активация → успех. Используй встроенный биллинг Chatium (разовая покупка/подписка). После успешной оплаты создай/обнови subscriptions (status=active) и поставь users.is_premium=true. Поддержи оплату до регистрации (по email).»
**Результат:** оплата активирует премиум.
**Проверка:** тестовая оплата → is_premium=true, премиум-практики открылись.
**Примечание:** если решено оставить GetCourse — вместо встроенного биллинга вызывай его по HTTP (см. `03-integrations.md`).

## Шаг 10. Нотификации об окончании триала

**Промпт:** «Отложенная задача раз в день: найди пользователей, у кого trial_ends_at был 1 час–7 дней назад, кто не премиум и кому ещё не слали уведомление trial_expired; отправь в Telegram сообщение с кнопкой "Оформить подписку" (ссылка на Mini App). Зафиксируй отправку (одно уведомление на пользователя).»
**Результат:** авто-нотификация ушедшим с триала.
**Проверка:** пользователю с истёкшим триалом приходит одно сообщение, повторно не шлётся.

## Шаг 11. Аналитика, локализация, онбординг

**Промпт:** «Подключи Yandex Metrika (счётчик 107703259) и события (открытие, каталог, избранное, пейволл, подписка, стрик). Добавь RU/EN локализацию (RU по умолчанию). Сделай онбординг при первом запуске (несколько слайдов с блобом).»
**Результат:** аналитика + i18n + онбординг.
**Проверка:** события уходят в Metrika; язык переключается; онбординг показывается один раз.
