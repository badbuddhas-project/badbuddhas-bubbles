# 01. Функциональная спецификация

Platform-agnostic описание «что построить». Ссылки на файлы оригинала даны как эталон поведения, не для копирования кода.

## Роли и доступ

- **Гость** — не авторизован. Видит каталог, но воспроизведение/избранное требуют входа.
- **Пользователь** — авторизован (через Telegram или email). Есть профиль, стрик, избранное.
- **Премиум-пользователь** — активная подписка ИЛИ активный триал. Доступны премиум-практики.

**Единый гейт доступа** (эталон — `hooks/useUser.ts`):
```
trialActive = trial_ends_at != null && trial_ends_at > now()
trialDaysLeft = trialActive ? ceil((trial_ends_at - now) / 1 день) : 0
hasAccess = is_premium || trialActive
```
`hasAccess` — единственная проверка, открывающая премиум-контент во всём приложении. Триал — 14 дней с момента регистрации.

## Экраны

### Главная `/`
- Hero-блок: крупный анимированный «дышащий» блоб (см. `04-design.md`), карусель по категориям.
- Плитки категорий: **relax / balance / energize** (внутренние ярлыки SLOW / GROUND / RISE).
- Блок «рекомендованные практики».
- Баннер с остатком дней триала (если триал активен): показывает `trialDaysLeft`.
- Навигация вниз — таб-бар (Главная, Каталог, Избранное, Профиль).

### Каталог `/catalog`
- Полный список практик (из таблицы `practices`, сортировка по `sort_order`).
- Фильтр по инструктору (query-параметр `?instructor=`).
- На каждой карточке — переключатель «в избранное».
- Тап по карточке → экран практики.

### Избранное `/favorites`
- Практики, добавленные пользователем в избранное. Пустое состояние, если ничего нет.

### Практика / плеер `/practice/[id]`
- Два режима: **detail** (описание практики, кнопка «начать») и **player** (проигрыватель).
- Аудио: play/pause, seek по прогресс-бару, отображение текущего времени и длительности (эталон — `hooks/useAudioPlayer.ts`).
- Переключатель «в избранное».
- **Гейтинг:** если практика `is_premium` и у пользователя нет `hasAccess` → редирект/переход на `/subscribe`.
- По завершении практики (`onComplete`) — записать сессию и пересчитать стрик (см. `02-data-model.md`, «Стрик»).

### Подписка / пейволл `/subscribe`
Пошаговый флоу: **landing → оплата → активация → успех**.
- *landing:* оффер подписки, кнопка оплатить.
- *оплата:* сейчас — iframe-виджет GetCourse (`public/gc-widget.html`). В Chatium — либо встроенный биллинг, либо сохранённый GetCourse (см. `03-integrations.md`).
- *активация:* после оплаты пользователь вводит/подтверждает email, система проверяет наличие оплаченной сделки и ставит `is_premium = true`.
- *успех:* подтверждение доступа.

### Профиль `/profile` (+ `/profile/settings`, `/profile/faq`)
- Текущий стрик, самый длинный стрик, всего практик, всего минут (из `user_stats`).
- Статус подписки (активна / триал / нет), сколько дней триала осталось.
- Модалка привязки email (`ConnectEmailModal`) — для Telegram-пользователей без email.
- Настройки, FAQ, выход, закрытие Mini App.

### Онбординг `/onboarding`
- Первый запуск (гейт по локальному флагу `badbuddhas_onboarding_completed`, эталон — `lib/constants.ts`). Несколько экранов-слайдов с блобами.

### Расписание `/schedule`
- Живые события/эфиры из внешнего календаря (AddEvent, см. `03-integrations.md`).

### Теория `/theory`
- Заглушка «Скоро». Можно опустить в первой версии.

### Аутентификация
- `/login`, `/register` — вход через Telegram (виджет/Mini App) + email/пароль.
- `/forgot-password`, `/reset-password` — сброс пароля по email.
- `/auth/confirm`, `/auth/callback` — подтверждение email.

> В Chatium авторизация встроенная (email/SMS/роли). Тремя путями оригинала (Telegram Mini App, Telegram Login Widget, email/пароль) можно управлять проще — см. `03-integrations.md`. Пароли/сброс/подтверждение email могут стать не нужны, если использовать нативную авторизацию Chatium.

## Локализация

RU/EN, RU — основной (эталон — `lib/i18n/`, `translations/ru.ts`, `en.ts`). Определять по языку Telegram/браузера, с переключателем в настройках.

## Аналитика (события)

Через всё приложение шлются события в Yandex Metrika (эталон — `lib/analytics.ts`, `docs/analytics-events.docx`). Ключевые: `app_opened`, `subscribe_*`, `favorite_toggled`, `streak_updated`, `email_gate_shown`, `premium_wall_shown`, просмотры каталога/избранного. В Chatium сохранить те же события (см. `03-integrations.md`).
