# 99. Доступы и секреты

Здесь только **имена** секретов и **где их взять**. Реальные значения (токены, ключи, пароли) в репозиторий **не коммитятся** — передаются отдельным защищённым каналом (пароль-менеджер) и подключаются через переменные/настройки Chatium.

> ⚠️ В рабочем дереве оригинала есть файл `.env.local.prod` с боевыми значениями — **не включайте его в пакет передачи и не коммитьте**. Значения оттуда передавайте только через защищённый канал.

## Доступы к платформам

| Доступ | Зачем | Где взять |
|---|---|---|
| Аккаунт Chatium (разработчик) | собрать и хостить приложение | регистрация на chatium.ru |
| Supabase (проект `wrkldpemfiqkgsstkaas`) | экспорт данных пользователей и каталога | владелец проекта (Стас) |
| Telegram Bot (@BadBuddhas_bubbles_bot) | токен бота, настройка Mini App в BotFather | владелец бота |
| GetCourse (`online.badbuddhas.ru`) | платежи/подписки, если оставляем GetCourse | админ GetCourse |
| Yandex Metrika (счётчик 107703259) | аналитика, Varioqub | доступ к счётчику |
| AddEvent | календарь расписания | владелец аккаунта AddEvent |
| Регистратор домена / DNS | перенос домена на Chatium | владелец домена |

## Переменные (имена из оригинала)

Понадобятся при воспроизведении интеграций (значения — из защищённого канала):

- `TELEGRAM_BOT_TOKEN` — токен бота (вход + отправка нотификаций).
- `TELEGRAM_WEBHOOK_SECRET` — секрет вебхука бота.
- `NEXT_PUBLIC_BOT_USERNAME` — username бота.
- `GETCOURSE_API_KEY`, `GETCOURSE_WRITE_API_KEY`, `GETCOURSE_WEBHOOK_SECRET` — если оставляем GetCourse.
- `ADDEVENT_API_TOKEN` — календарь расписания.
- `NEXT_PUBLIC_YM_COUNTER_ID` — счётчик Metrika (107703259).
- `SUPABASE_SERVICE_ROLE_KEY`, `NEXT_PUBLIC_SUPABASE_URL` — только для экспорта данных при миграции.

## Не понадобится в Chatium (заменяется платформой)

- `JWT_SECRET` — своя сессия не нужна, авторизация Chatium.
- `RESEND_API_KEY` — письма/сброс пароля берёт на себя авторизация Chatium.
- `CRON_SECRET` — крон заменяют отложенные задачи Chatium.
- `NEXT_PUBLIC_APP_URL` — домен настраивается в Chatium.
