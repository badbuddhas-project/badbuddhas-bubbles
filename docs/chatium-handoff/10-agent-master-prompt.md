Ты — разработчик на платформе Chatium. Собери мобильное + веб приложение **BadBuddhas Bubbles** — плеер дыхательных практик (аудио-медитации) для Telegram Mini App и веба. Аудитория русскоязычная, интерфейс на русском, тема тёмная. Используй возможности Chatium: экраны (`app.screen`) с JSX-компонентами, БД Heap, встроенную авторизацию, медиасервис для аудио, отложенные задачи для нотификаций.

## Модель данных (таблицы Heap)

Создай типизированные таблицы:

- **users**: telegram_id (int, уникальный), username, first_name, email (уникальный), is_premium (bool), trial_ends_at (datetime), created_at. Один пользователь — из Telegram и/или email.
- **practices**: title_ru, title, duration_seconds (int), category (enum: relax | balance | energize), instructor_name, instructor_avatar_url, audio_url, preview_image_url, is_premium (bool), sort_order (int). Наполняется вручную.
- **user_practices**: user_id → users, practice_id → practices, completed_at (datetime), listened_seconds (int). История прослушиваний.
- **user_stats** (1:1 с users): user_id, current_streak (int), longest_streak (int), total_practices (int), total_minutes (int), last_practice_date (date). Создавай вместе с пользователем.
- **favorites**: user_id → users, practice_id → practices, уникальная пара (user_id, practice_id).
- **subscriptions**: user_id → users (может быть пустым), email, status (active | expired), expires_at, created_at. Оплата возможна до регистрации (строка по email без user_id).

## Авторизация и роли

- Вход через **Telegram**: при открытии Mini App принимай `initData`, верифицируй подпись (HMAC по токену бота), находи/создавай пользователя в users по telegram_id. Поддержи также вход по email средствами Chatium.
- Триал: при создании пользователя ставь `trial_ends_at = now + 14 дней`.
- **Единый гейт доступа:** `hasAccess = is_premium ИЛИ (trial_ends_at > сейчас)`. Только он открывает премиум-контент.

## Экраны

1. **Главная** — крупный анимированный «дышащий» блоб (пульсация), плитки категорий relax/balance/energize, блок рекомендованных практик, баннер с остатком дней триала. Внизу — таб-бар: Главная / Каталог / Избранное / Профиль.
2. **Каталог** — все практики из `practices` (сортировка по sort_order), фильтр по инструктору, кнопка «в избранное» на карточке.
3. **Избранное** — практики, добавленные пользователем; пустое состояние.
4. **Практика/плеер** — режим описания и режим проигрывателя: аудио из медиасервиса с play/pause, перемоткой (seek), текущим временем и длительностью. Кнопка «в избранное». Если практика премиум и нет hasAccess → отправляй на экран подписки. По окончании — запиши сессию в user_practices и пересчитай стрик.
5. **Подписка** — оффер → оплата → активация → успех. Оплата: используй встроенный биллинг Chatium (разовая покупка/подписка). После оплаты ставь subscriptions.status=active и users.is_premium=true.
6. **Профиль** — текущий стрик, рекорд, всего практик, всего минут; статус подписки и дни триала; привязка email; выход.
7. **Онбординг** — несколько слайдов при первом запуске.

## Стрик (важно)

После каждой завершённой практики пересчитывай стрик **из истории user_practices** (не инкрементально):
- взять уникальные даты практик в таймзоне **Europe/Moscow**;
- current_streak = длина непрерывной серии дней, заканчивающейся на последнюю дату;
- longest_streak = максимальная серия; total_practices = число записей; total_minutes = сумма listened_seconds / 60;
- longest_streak / total_* никогда не уменьшай (бери максимум со старым значением).
Расчёт должен быть идемпотентным: пересчёт всегда даёт верный результат.

## Медиа

Аудио и обложки практик — в медиасервисе Chatium; в `practices` хранятся их URL. Обеспечь стриминг аудио с перемоткой.

## Дизайн

- Тема тёмная: фон `#000000`, текст `#FFFFFF`. Шрифт — Wix Madefor Display (или ближайший гротеск).
- Цвета категорий: relax `#8B5CF6` (фиолетовый), balance `#3B82F6` (синий), energize `#EC4899` (розовый). Блобы — мягкие круги/радиальные градиенты этих цветов с полупрозрачными пузырьками.
- «Дышащий» блоб на главной и в онбординге должен непрерывно анимироваться (пульсация). Если keyframe-анимация недоступна — используй зацикленное видео или статичную картинку.

## Аналитика

Подключи Yandex Metrika (счётчик 107703259) и отправляй события: открытие приложения, просмотр каталога/избранного, переключение избранного, показ пейволла, оформление подписки, обновление стрика.

## Нотификации

Отложенной задачей раз в день находи пользователей, у кого триал закончился 1 час–7 дней назад и кому ещё не слали уведомление, и отправляй в Telegram сообщение с кнопкой «Оформить подписку» (ссылка на Mini App). Фиксируй факт отправки, чтобы не слать повторно.

## Критерий готовности

Каталог тянется из Heap; плеер играет аудио с перемоткой; вход через Telegram создаёт пользователя; избранное сохраняется; премиум-практики закрыты гейтом с учётом триала; стрик считается по МСК; профиль показывает статистику; подписка активирует премиум.
