# BadBuddhas Bubbles → Chatium: пакет передачи

Этот пакет — всё, что нужно, чтобы **заново собрать приложение BadBuddhas Bubbles на платформе [Chatium](https://chatium.ru)**. Оригинал написан на Next.js + Supabase + Vercel; вы будете воспроизводить его на Chatium (TypeScript + JSX, БД Heap, встроенные авторизация/медиасервис/отложенные задачи). Код оригинала **не переносится напрямую** — это референс-эталон, а не исходник для копипаста.

## Что за приложение

**BadBuddhas Bubbles** — Telegram Mini App + веб-приложение с дыхательными практиками (аудио-медитации). Пользователь слушает практики, копит «стрик» (серию дней подряд), добавляет в избранное, первые 14 дней — бесплатный триал, дальше — платная подписка. Аудитория русскоязычная (есть EN-локализация).

## Рекомендованный порядок работы

1. Прочитать `01`–`05`, чтобы понять продукт целиком.
2. Получить доступы по `99-secrets-checklist.md`.
3. Загрузить медиа (`05-assets.md`) в медиасервис Chatium.
4. Собрать приложение через ИИ-агента: сначала `10-agent-master-prompt.md`, потом дошлифовать пошаговыми промптами `11`.
5. Проверить по чек-листу готовности (ниже).
6. Перенести данные пользователей (`07-data-migration.md`).
7. Переключить домен и Telegram (`06-server-domain-github.md`).

## Открытые вопросы к Chatium (уточнить у support@chatium.ru до старта)

- Поддержка непрерывной (keyframe/loop) анимации — нужна для «дышащего» блоба на главной (`04-design.md`).
- Загрузка кастомного шрифта (Wix Madefor Display).
- Приём Telegram Mini App `initData` и верификация HMAC на серверном TS; нативная интеграция с Telegram-ботами (`03-integrations.md`).
- Возможности встроенного биллинга vs. сохранение GetCourse по HTTP (`03-integrations.md`).
- Произвольные исходящие HTTPS-запросы к внешним API (GetCourse, Yandex, AddEvent, Telegram).
- Выпуск TLS для своего домена (свой сертификат от доверенного ЦС / Минцифры?).
- Экспорт кода и данных из Chatium (оценить вендор-лок).

## Чек-лист «готово к запуску»

- [ ] Каталог практик отображается, тянется из Heap.
- [ ] Плеер играет аудио с seek и корректной длительностью.
- [ ] Вход через Telegram создаёт/находит пользователя.
- [ ] Избранное добавляется/убирается и сохраняется.
- [ ] Премиум-практики закрыты гейтом для не-подписчиков (с учётом 14-дневного триала).
- [ ] Стрик считается по завершённым практикам (TZ Europe/Moscow).
- [ ] Профиль показывает стрик, статистику, статус подписки.
- [ ] Экран подписки ведёт к оплате и активирует премиум.
- [ ] Нотификация об окончании триала уходит в Telegram.
- [ ] Данные существующих пользователей перенесены, премиум/стрики на месте.
- [ ] Домен и web-app URL Mini App переключены.

> **Важно про безопасность:** в этом пакете нет реальных паролей, ключей и токенов — только их имена и где взять. См. `99-secrets-checklist.md`.
