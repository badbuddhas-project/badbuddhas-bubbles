# 07. Перенос данных пользователей

Цель — существующие пользователи после переезда **не теряют** премиум, стрики и историю. Данные лежат в Supabase (ref `wrkldpemfiqkgsstkaas`).

## Что переносим

| Таблица | Зачем |
|---|---|
| `users` | сами пользователи + связки `telegram_id`/`email`, `is_premium`, `trial_ends_at` |
| `subscriptions` | активные/истёкшие подписки (в т.ч. pending по email) |
| `user_practices` | история — из неё **пересчитывается стрик** |
| `user_stats` | текущие стрик/статистика (можно и пересчитать из истории) |
| `favorites` | избранное |
| `practices` | каталог (+ актуальные URL медиа, см. `05-assets.md`) |
| `notification_log` | по желанию — история нотификаций/атрибуция |

## Порядок

1. **Экспорт** из Supabase (SQL / Table Editor → CSV, либо `pg_dump`). Экспортировать таблицы выше.
2. **Загрузить медиа** в медиасервис Chatium и получить новые URL (см. `05-assets.md`).
3. **Импорт в Heap** Chatium: создать таблицы (`02-data-model.md`), залить строки. Сохранить исходные `id`, чтобы не порвать связи `user_id` / `practice_id`.
4. В `practices` подменить `audio_url` / `preview_image_url` / `instructor_avatar_url` на новые URL Chatium.
5. **Пересчитать стрик** каждому пользователю из `user_practices` (логика в `02-data-model.md`) — надёжнее, чем доверять перенесённому `user_stats`.
6. **Сверка** (обязательно): число пользователей до/после; число активных подписок; сумма `is_premium=true`; несколько выборочных пользователей — стрик и избранное совпадают.

## Ключевое: не потерять идентичность

Пользователь опознаётся по **`telegram_id`** и/или **`email`**. При импорте и при новой авторизации Chatium эти связки должны сматчиться на ту же запись — иначе человек «потеряет» премиум и стрик. Особое внимание:
- pending-подписки в `subscriptions` (оплата до регистрации) — привязаны по `email`, `user_id` может быть NULL.
- пользователи, у которых есть и `telegram_id`, и `email` (прошли merge-аккаунтов).

## После миграции

- Оставить Supabase в read-only на переходный период как страховку (не удалять сразу).
- Сверить, что новые практики/оплаты пишутся уже только в Chatium.
