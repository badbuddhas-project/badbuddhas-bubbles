# 09. Пошаговый ранбук для принимающей стороны

Линейная инструкция «делай по порядку» — от входа в GitHub до работающего приложения на Chatium. Каждый шаг ссылается на подробный документ пакета. Не пропускай шаги.

---

## Этап 1. Доступ к коду (GitHub)

**Шаг 1.1.** войди в аккаунт на [github.com](https://github.com).

**Шаг 1.2.** Открой репозиторий в браузере и найди папку `**docs/chatium-handoff/`** — это твой основной пакет знаний. Читать можно прямо в вебе, ничего скачивать пока не нужно.

> Клонировать код на компьютер не обязательно: приложение ты будешь строить в Chatium, а репозиторий нужен как **эталон** (спецификация, логика, дизайн). Если удобнее локально — установи git и выполни `git clone https://github.com/badbuddhas-project/badbuddhas-bubbles.git`.

---

## Этап 2. Понять продукт

**Шаг 2.1.** Прочитай по порядку: `00-README.md` → `01-product-spec.md` → `02-data-model.md` → `03-integrations.md` → `04-design.md` → `05-assets.md`.

**Шаг 2.2.** Держи в голове главное: это плеер дыхательных практик (Telegram + веб); ключевое — каталог аудио, проигрыватель, стрик, избранное, 14-дневный триал и премиум-гейт (`hasAccess`).

---

## Этап 3. Получить доступы и материалы

**Шаг 3.1.** По списку `99-secrets-checklist.md` запроси у владельца (через защищённый канал, НЕ через GitHub):

- аккаунт Chatium,
- токен Telegram-бота + права в @BotFather,
- доступ к GetCourse, Yandex Metrika, AddEvent,
- доступ к DNS/домену.

**Шаг 3.2.** Получи от владельца **выгрузку данных и медиа** — папку `supabase-export/` (её нет в GitHub, т.к. там персональные данные): JSON-дампы таблиц + аудиофайлы практик + таблицы сопоставления `full_track_map.csv`.

---

## Этап 4. Поднять окружение Chatium

**Шаг 4.1.** Войди в [chatium.ru](https://chatium.ru), создай проект/приложение. Разберись с web-IDE (редактор кода) — код на TypeScript + JSX.

**Шаг 4.2.** Перед стартом задай в [support@chatium.ru](mailto:support@chatium.ru) «Открытые вопросы» из `00-README.md` (анимация блоба, шрифт, приём Telegram initData, биллинг, внешние HTTP, TLS домена). Ответы влияют на решения ниже.

---

## Этап 5. Загрузить медиа

**Шаг 5.1.** Загрузи аудиофайлы практик (из `supabase-export/dasha_chen_audio/` и `other_practices_audio/`) в медиасервис Chatium.

**Шаг 5.2.** Загрузи картинки инструкторов/обложки.

**Шаг 5.3.** Сверяйся с `full_track_map.csv` — имена файлов техничные и не совпадают с названиями в приложении (`silvio_bondage_AdobeExpress.mp3` = «Присутствуй»). Запиши для каждой практики новый URL в Chatium — понадобится на шаге 6.

---

## Этап 6. Собрать приложение (через ИИ-агента Chatium)

**Шаг 6.1.** Открой ИИ-агента Chatium. Вставь **мастер-промпт** из `10-agent-master-prompt.md` (замени плейсхолдеры, секреты НЕ вставляй — подключай через настройки Chatium).

**Шаг 6.2.** Дальше иди **пошаговыми промптами** из `11-agent-step-prompts.md` (шаги 1–12): модель данных → авторизация Telegram → каталог → плеер → избранное → стрик → гейтинг → профиль → подписка → нотификации → аналитика/i18n/онбординг.

**Шаг 6.3.** После каждого промпта проверяй результат по разделу «Проверка» этого шага. Не переходи дальше, пока текущий шаг не работает.

---

## Этап 7. Наполнить каталог

**Шаг 7.1.** Создай в Heap записи практик из `supabase-export/practices.json` (36 штук). Категории — `slow`/`ground`/`rise`. Проставь новые URL медиа из шага 5.3, флаги `is_premium` и `is_visible` (в проде многие практики скрыты — `is_visible=false`).

**Шаг 7.2.** Проверь: каталог показывает только видимые практики, аудио играет, обложки на месте.

---

## Этап 8. Перенести данные пользователей

**Шаг 8.1.** По `07-data-migration.md` импортируй в Heap: `users`, `subscriptions`, `user_practices`, `user_stats`, `favorites` (из `supabase-export/*.json`). Сохрани исходные id и связки `telegram_id`/`email`.

**Шаг 8.2.** Пересчитай стрик каждому пользователю из истории (логика в `02-data-model.md`).

**Шаг 8.3.** Сверка: число пользователей, активных подписок, премиумов — до/после совпадает.

---

## Этап 9. Переключение (cutover)

**Шаг 9.1.** По `06-server-domain-github.md`: перенаправь DNS домена на Chatium, выпусти TLS.

**Шаг 9.2.** В @BotFather поменяй web-app URL Mini App на новый адрес (иначе Telegram-вход сломается).

**Шаг 9.3.** Обнови return URL/настройки GetCourse и коллбэки вебхуков.

**Шаг 9.4.** Пройди финальный чек-лист «готово к запуску» из `00-README.md`.

---

## Этап 10. Финализация

**Шаг 10.1.** Отметь выполненное в таблице `08-handover-checklist.md`.

**Шаг 10.2.** Убедись, что новые оплаты/практики пишутся только в Chatium.

**Шаг 10.3.** Сообщи владельцу — он переведёт GitHub-репозиторий и Supabase в архив (read-only), не удаляя.
