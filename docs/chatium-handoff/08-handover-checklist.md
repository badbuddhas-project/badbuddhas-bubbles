# 08. Чек-лист передачи кодовой базы

Пошаговая передача проекта новому человеку. Кодовая база отдаётся **не как папка с файлами, а как доступ к репозиторию + пакет знаний + доступы**. Отмечайте пункты по мере выполнения.

## A. Код (GitHub)

- [ ] Всё запушено в `badbuddhas-project/badbuddhas-bubbles`, рабочее дерево чистое.
- [ ] Секретов в истории git нет; `.env*` покрыты `.gitignore` (в т.ч. `.env.local.prod` — боевые значения не коммитятся).
- [ ] Новому человеку выдан доступ к репозиторию: **read** (GitHub → Settings → Collaborators, либо через организацию/команду). Для Chatium-миграции достаточно read — репо служит эталоном, не боевым источником.
- [ ] Если нужна автономная работа — сделан **fork** или передано владение репо.

## B. Пакет знаний

- [ ] Передана папка [`docs/chatium-handoff/`](.) целиком (идёт вместе с репо).
- [ ] Новый человек прочитал `00-README.md` и понимает порядок работы.

## C. Секреты и доступы (НЕ через GitHub / НЕ в коде)

Каждый пункт — через пароль-менеджер / защищённый канал, по списку `99-secrets-checklist.md`:

- [ ] Аккаунт/доступ **Chatium** (разработчик).
- [ ] **Telegram Bot** (@BadBuddhas_bubbles_bot): токен + права на настройку Mini App в BotFather.
- [ ] **Supabase** (проект `wrkldpemfiqkgsstkaas`): доступ для экспорта данных.
- [ ] **GetCourse** (`online.badbuddhas.ru`): доступ, если платежи остаются на GetCourse.
- [ ] **Yandex Metrika** (счётчик 107703259) + Varioqub.
- [ ] **AddEvent**: токен календаря расписания.
- [ ] **DNS / регистратор домена**: для переноса домена на Chatium.

## D. Данные пользователей

- [ ] Экспорт из Supabase (`users`, `subscriptions`, `user_practices`, `user_stats`, `favorites`, `practices`) — по `07-data-migration.md`; либо выдан read-доступ к проекту Supabase для самостоятельного экспорта.
- [ ] Скачаны медиа-мастера (аудио/картинки) из Supabase Storage — по `05-assets.md`.

## E. Финализация

- [ ] Пройден чек-лист «готово к запуску» из `00-README.md` (приложение на Chatium собрано и проверено).
- [ ] Данные пользователей перенесены и сверены (число пользователей, активные подписки, стрики) — по `07-data-migration.md`.
- [ ] Домен и web-app URL Mini App в BotFather переключены на Chatium — по `06-server-domain-github.md`.
- [ ] GitHub-репозиторий переведён в архив (read-only), **не удалён** — остаётся как история и эталон.
- [ ] Supabase на переходный период оставлен read-only как страховка; удаление — только после подтверждённой стабильной работы Chatium.
